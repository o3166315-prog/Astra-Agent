Astra Agent

An open-source AI agent designed to help developers work smarter.

Astra Agent brings AI-powered assistance into a single application, with support for multiple AI providers and local models.

Features

- Support for multiple AI providers.
- Local AI model integration through Ollama.
- AI-powered development assistance.
- Conversation history.
- Secure credential storage.
- Developer-focused interface.

Requirements

Before installing Astra Agent, make sure you have:

- "Node.js" (https://nodejs.org/) installed.
- npm (included with Node.js).
- Git (optional).

Installation

1. Download the latest Astra Agent ZIP file from this repository.
2. Extract the ZIP archive.
3. Open a terminal inside the extracted "AstraAgent-1.7.0" folder.
4. Install the dependencies:

npm install

Running Astra Agent

To see the available commands defined by the project:

npm run

Use the appropriate start or development command displayed in the list.

Testing

Run the test suite:

npm test

To run integration tests:

npm run test:integration

Troubleshooting

Dependencies fail to install

- Make sure Node.js and npm are installed.
- Try running "npm install" again.

A command is not recognized

- Make sure your terminal is open in the project folder.
- Run "npm run" to list the available scripts.
